### 1.1 User - 用户表
| 字段名 | 类型 | 约束 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| id | Integer | PK, 自增 | \- | 主键 |
| username | String | NOT NULL, UNIQUE, INDEX | \- | 用户显示名称 |
| uid | String | NOT NULL, UNIQUE, INDEX | \- | 用户登录标识 |
| phone\_number | String | NULLABLE, UNIQUE, INDEX | \- | 手机号 |
| avatar | String | NULLABLE | \- | 头像 URL |
| password\_hash | String | NOT NULL | \- | 密码哈希 |
| role | String | NOT NULL | "user" | 角色：superadmin/admin/user |
| created\_at | DateTime | \- | utc\_now\_naive() | 创建时间 |
| last\_login | DateTime | NULLABLE | \- | 最后登录时间 |
| login\_failed\_count | Integer | NOT NULL | 0 | 登录失败次数 |
| last\_failed\_login | DateTime | NULLABLE | \- | 最后一次登录失败时间 |
| login\_locked\_until | DateTime | NULLABLE | \- | 账户锁定截止时间 |
| is\_deleted | Integer | NOT NULL, INDEX | 0 | 软删除标记：0=正常，1=已删除 |
| deleted\_at | DateTime | NULLABLE | \- | 删除时间 |

**关联关系：**

    
*   `operation_logs`: 一对多关联 OperationLog，级联删除
    
*   `api_keys`: 一对多关联 APIKey，级联删除
    
*   `agent_env`: 一对一关联 AgentEnv，级联删除
    

**业务方法：**

*   `is_login_locked()`: 检查账户是否锁定
    
*   `get_remaining_lock_time()`: 获取剩余锁定时间（秒）
    
*   `increment_failed_login()`: 增加登录失败计数
    
*   `reset_failed_login()`: 重置登录失败状态
